# 📜 公會知識傳承結界 (企業內部學習系統)

### 【建構動機】我認為公會需要建立一座知識殿堂，以達成以下戰略目標：
- **英雄歷程追蹤**：管理成員與研習進度（精準追蹤誰在什麼時間完成了哪項試煉）。
- **多元法典庫**：提供多樣化的典籍與卷軸，包含羊皮紙文件、紀錄水晶（影片）與幻境模擬（互動課程）。
- **成就解鎖與授勳**：自動判定試煉完成條件，並核發「結訓徽章與證書」。
- **戰力稽核報告**：產出完成率與戰備紀錄，用來對內監督或對外展示（確保全員都具備基礎守護意識，如資安訓練）。
- **自動化信使**：整合魔法信使（自動寄信）提供任務提醒、結訓通知等流程。

### 【結界架構】我目前構思的陣法架構大概長這樣：
- **Moodle (智慧中樞/LMS)**：這是整個陣法的「大腦」，我用它來管理學徒、試煉、魔法積分、徽章和報表。
- **PostgreSQL (記憶魔晶/DB)**：用來儲存 Moodle 所有的底層紀錄與資料。
- **Adapt Authoring Tool (幻境工坊)**：我打算用這個來製作互動式幻境，再封裝成 **SCORM 卷軸** 供 Moodle 讀取。
- **n8n (自動化工坊)**：我會透過 API 連結 Moodle 的魔力脈絡，來驅動「自動信使和流程自動化」（像是任務催繳或結訓廣播）。
- **Mail Server (SMTP 通訊塔)**：讓 Moodle 和 n8n 都能向總部派發皇家信件。
- **DNS／反向代理／SSL (結界防護罩)**：這部分我會請防護結界師團隊（網管）幫忙，把服務掛載到公會的專屬領地（網域）下。

### 【卷軸製作】關於課程內容的編纂，我打算這樣做：
- **古代典籍（文字教材）**：
    - 我會先用 Markdown（像是 Obsidian 這把法杖）撰寫咒文原稿。
    - 然後轉化為：
        - HTML：銘刻進 Moodle 的「卷軸頁面」或「法典書本」。
        - PDF：當作「實體卷軸」上傳供學徒下載。
- **幻境試煉（互動課程）**：
    - 我用 Adapt 編寫好劇本後，匯出成 **SCORM 標準卷軸**。
    - 放入 Moodle 的「SCORM 試煉場」裡追蹤探索進度。
- **記憶水晶（媒體檔案）**：
    - 文件使用 **PDF** 格式，圖像利用 PNG/JPG，影像則封裝為 mp4 格式或嵌入公會專屬的影音結界。

### 【中樞設定】在 Moodle 這台大腦中，我會進行以下關鍵魔力調校：
- 開啟試煉場地（像是「守護結界防禦（資安）內訓」），把 PDF、紀錄水晶、SCORM 卷軸跟試煉測驗都放置妥當。
- 設定好「活動通關條件」跟「課程滿級條件」。
- 裝設好 Custom certificate 魔法陣（外掛），設定學徒「滿級通關後」才能獲得專屬徽章。
- 點亮 SMTP 通訊塔，讓系統可以自動發佈招募公告或錄取信。

### 【自動化運轉】至於法陣的自動化流程，我會依賴 n8n 使魔來代勞：
- 我會在 Moodle 生成專屬的 API 魔杖（Token），然後讓 n8n 定期去巡迴探測：
    - 誰的歷程還卡關？
    - 誰剛剛打破了試煉紀錄（完課）？
- 我計畫排程這些魔法任務：
    - 每週派遣信使寄送「未完成警告」給學徒，同時副本給公會長（主管）。
    - 學徒一通關，就自動觸發「結訓祝賀與電子徽章」。
    - 定期將試煉完成率的地圖報告，派送給招募官（HR）或防禦指揮官（資安負責人）。
