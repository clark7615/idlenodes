# 🤖 奧術人偶 召喚術：從預測之靈到行動先知

> [!BOOK] 法典引言
> 對話式奧數僕從 雖然強大，但它只是一個被動的預測之靈——只能回答問題，無法主動行動。**奧術人偶 召喚術** 將教會你如何賦予預測之靈「雙手」，讓它從回答者進化為行動者。

---

## 一、人偶 的本質：大腦 + 雙手

你可能會問：「人偶 和一般的 對話式奧數僕從 有什麼不同？」答案是：**人偶 = 對話式奧數僕從 (大腦) + 行為插槽 (雙手)**。

### 人偶 的定義

| 組件 | 功能 | 範例 |
|:---|:---|:---|
| 🧠 對話式奧數僕從 (大腦) | 思考、規劃、決策 | GPT-4、Claude |
| 🤲 行為插槽 (雙手) | 執行具體操作 | 搜尋、計算、寫入檔案 |

### 從被動到主動

| 類型 | 特性 | 限制 |
|:---|:---|:---|
| 純 對話式奧數僕從 | 只能回答問題 | 無法獲取即時資訊 |
| 奧術人偶 | 能主動使用工具 | 依賴工具定義的品質 |

---

## 二、行為插槽：預測之靈的雙手

### 行為插槽 是什麼？

行為插槽 是 對話式奧數僕從 可以呼叫的外部功能或 API。

**常見 行為插槽 類型**：

| 類型 | 說明 | 範例 |
|:---|:---|:---|
| 🔍 搜尋類 | 取得即時資訊 | Web Search、Data Lookup |
| 🧮 計算類 | 精確數學運算 | Calculator、SQL Query |
| 📁 檔案類 | 讀寫檔案系統 | Read File、Write File |
| 🔌 API 類 | 串接外部服務 | Email、Calendar、Slack |

### 行為插槽 的執行機制

對話式奧數僕從 的輸出不僅是文字，還可以包含「工具呼叫指令」：

```
工具呼叫：web_search(query="2024年諾貝爾物理學獎得主")
```

## 三、MCP：工具召喚的通用魔法陣

### MCP 是什麼？

MCP (Model Context Protocol) 是一套用來串接 對話式奧數僕從 與外部工具的協議規範。

> [!TIP] 冒險者筆記
> MCP 就像是一個「魔法陣」，讓不同的工具都能被 對話式奧數僕從 統一呼叫。

### MCP 的三大角色

| 角色 | 說明 |
|:---|:---|
| 🔵 MCP Client | 請求工具的 對話式奧數僕從 |
| 🟢 MCP Server | 提供工具的服務 |
| 🟠 行為插槽 | 具體的工具功能 |

### 為什麼要學 MCP？

- **統一標準**：不同工具都能用同樣方式呼叫
- **可擴充性**：輕鬆新增或替換工具
- **安全性**：明確定義工具的使用權限

---

## 四、技能組：預組裝的技能卷軸

### 技能組 是什麼？

技能組 是一種更高階的工具封裝，將多個 行為插槽 與 提示詞 整合成一個完整的任務模組。

**技能組 vs 行為插槽 的差異**：

| 項目 | 行為插槽 | 技能組 |
|:---|:---|:---|
| 精細度 | 單一功能 | 多步驟任務 |
| 使用方式 | 呼叫函數 | 觸發任務流 |
| 範例 | `web_search()` | `research_paper()` |

---

## 五、奧術人偶 架構

### ReAct 架構

**ReAct = Reasoning + Acting**，讓 人偶 交替進行「思考」與「行動」。

**流程**：

1. 🧠 **思考**：分析當前狀況
2. 🤲 **行動**：選擇並執行工具
3. 📊 **觀察**：獲取工具結果
4. 🔄 **循環**：重複 1-3 直到完成

### 3A 架構

**3A = Action + Adaptation + Adaptability**

- **Action**：能執行具體操作
- **Adaptation**：能根據結果調整策略
- **Adaptability**：能從經驗中學習改進

## 六、實戰範例：研究論文

### 使用者的需求

「幫我研究 2024 年諾貝爾物理學獎的相關論文」

### 人偶 的執行流程

1. **搜尋階段**：使用 `web_search` 工具查詢最新資訊
2. **整理階段**：使用 `summarize` 工具歸納重點
3. **撰寫階段**：使用 `write_file` 工具儲存報告
4. **回覆階段**：向使用者報告完成結果

---

## 🔑 核心觀念總結

- **人偶 = 大腦 + 雙手**：對話式奧數僕從 負責思考，行為插槽 負責行動
- **MCP 是通用協議**：讓不同工具都能被 對話式奧數僕從 呼叫
- **技能組 是技能封裝**：將多個工具整合成完整任務
- **ReAct 是主流架構**：思考→行動→觀察的循環模式
