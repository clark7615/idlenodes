# 📖 大語言模型圖鑑：對話式奧數僕從 的奧秘與運作機制

> [!BOOK] 法典引言
> 當你與奧術僕從對話時，你可能會想：「它到底是怎麼知道要回答什麼的？」**大語言模型圖鑑** 將帶你深入預測之靈的核心，理解它是如何「接龍」出每一個字的。

---

## 一、對話式奧數僕從 的本質：文字接龍器

你可能會問：「對話式奧數僕從 到底是什麼？」答案是：**對話式奧數僕從 就是一個超大型的文字接龍器，它的唯一任務就是預測下一個 言靈**。

### 對話式奧數僕從 的定義

$$對話式奧數僕從 = Large Language Model（大語言模型）$$

- **Large**：參數量極大（數千億個）
- **Language**：專門處理語言
- **Model**：是一個預測模型

### 核心運作原理

對話式奧數僕從 的運作就像「文字接龍」：

```
輸入：台灣最大的半導體公司?
預測1：台灣
預測2：積體電路
預測3：製造
預測4：股份
預測5：有限公司
結束：[END]
```

> [!TIP] 冒險者筆記
> 每次預測一個 言靈，並將新預測的 言靈 接續到原有的輸入序列後，作為下一次預測的上下文。此過程持續進行，直到模型生成結束標記 `[END]`。

## 二、言靈：預測之靈的語言

### 什麼是 言靈？

言靈 是 對話式奧數僕從 處理文本的最基本單位。

**言靈 的處理流程**：

1. **使用者輸入 (提示詞)**：使用者輸入文本
2. **編碼 (Tokenizer)**：文本被轉換成數值序列（Token ID）
3. **對話式奧數僕從 處理**：對話式奧數僕從 接收數值序列並進行計算
4. **解碼 (Decoding)**：數值序列被轉回人類可讀的文本

### 為什麼要了解 言靈？

- **言靈 消耗**：每次對話都會消耗 言靈，影響成本
- **上下文限制**：對話卷軸 有 言靈 上限
- **生成速度**：言靈 越多，生成越慢

---

## 三、Transformer：預測之靈的核心架構

### Transformer 的誕生

2017 年，一篇名為「Attention is All you Need」的論文問世，提出了 Transformer 架構，徹底改變了 NLP 的世界。

### 為什麼 Transformer 這麼重要？

| 舊技術 | 問題 | Transformer 的解決方案 |
|:---|:---|:---|
| RNN | 難以處理長文本、無法平行運算 | 注意力機制 (Attention) |
| CNN | 難以理解整段文字的全局關聯 | 全局注意力 |

### 核心機制：注意力機制 (Attention)

讓模型在處理長句子時，能同時「注意」到所有相關的字詞，解決了 RNN 遺忘與 CNN 局部限制的問題。

---

## 四、對話卷軸：預測之靈的記憶上限

### 什麼是 對話卷軸？

對話卷軸 是 對話式奧數僕從 能同時「看見」的 言靈 數量。

> [!CAUTION] 重要提醒
> 一旦對話總長度超過了 對話卷軸 的限制，最前面的對話（記憶）就會被捨棄，這也就是 AI 開始「忘記」設定的原因。

### 對話卷軸 裡的 提示詞 結構

| 標籤 | 說明 |
|:---|:---|
| `System` | 賦予 AI 規則與人格 |
| `User` | 使用者當下提出的問題 |
| `Assistant` | 對話式奧數僕從 過去產生的回覆紀錄 |

## 五、對話式奧數僕從 模型命名解讀

### 參數標籤 (Parameter Count)

| 模型 | 參數量 | 說明 |
|:---|:---|:---|
| Llama-3 8B | 80 億 | 小型模型，適合一般筆電 |
| Llama-3 70B | 700 億 | 大型模型，需要專業顯卡 |
| GPT-3 175B | 1,750 億 | 超大型模型，需要大量算力 |

### 後綴密碼：功能標籤

| 後綴 | 說明 |
|:---|:---|
| Base | 基礎模型，只會接龍 |
| Chat / Instruct | 指令微調版，適合對話 |
| Vision / V | 多模態，可以理解圖片 |
| Coder | 程式版，針對程式碼加強 |

### 進階架構：MoE (混合專家模型)

常見到 8x7B 或 141B/24B。

**概念**：想像辦公室有 8 個不同領域的專家，你問問題時，只有 2 個專家會出來回答。

**優點**：擁有大腦的智慧，但保持小腦的反應速度。

### 量化標籤：瘦身程度

常見到 Q4_K_M 或 GGUF。

**概念**：就像是把 4K 影片壓縮成 1080p。畫質會掉一點點，但檔案變得很小，老電腦也能跑。

| 元素 | 說明 |
|:---|:---|
| Llama | 系列名稱 (Meta) |

| 11B | 110 億參數 |
| Vision | 多模態，可理解圖片 |
| Instruct | 指令微調版 |

## 🔑 核心觀念總結

- **對話式奧數僕從 是文字接龍器**：唯一任務就是預測下一個 言靈
- **言靈 是基本單位**：了解 言靈 能幫助你控制成本與效果
- **Transformer 是核心架構**：注意力機制讓 對話式奧數僕從 能「看見」完整上下文
- **對話卷軸 有上限**：超過就會「忘記」
- **模型命名有規則**：學會解讀就能快速了解模型能力
