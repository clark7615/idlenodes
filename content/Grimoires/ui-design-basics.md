# 🖌️ 視覺工坊：UI 設計基礎法則與美學

> [!BOOK] 工坊引言
> UI 設計不僅是裝飾，更是與冒險者（使用者）之間的無聲契約。透過精準的視覺引導，我們能讓使用者在複雜的系統中不迷失方向，感受到設計的平衡與純粹。

---

## 🎨 第一章：構圖的奧秘

*   **視覺層次 (Hierarchy)**：
    *   **術式**：調整大小、顏色深度與位置，引導使用者的視線焦點。
    *   **效果**：確保最重要的信息（如標題、提示）第一時間映入眼簾。
*   **視覺平衡 (Alignment)**：
    *   **對稱平衡**：展現莊重與穩定感，適合正式文獻。
    *   **非對稱平衡**：注入生命力與現代感。
*   **能量對比 (Contrast)**：
    *   **術式**：運用色彩與字體的極大化差異，突顯關鍵行動點 (CTA)。

---

## 🛠️ 第二章：控件的靈學（生命週期）

每一個控件（按鈕、文字框）都具備不同的 **魔法狀態**：
*   **常規 (Default)**：靜止待命。
*   **懸停 (Hover)**：感受到冒險者的視線接觸，產生微光反應。
*   **觸發 (Active/Click)**：咒語施放瞬間。
*   **禁用 (Disabled)**：能量耗盡，暫時無法回應。

---

## 📏 第三章：柵格系統：領地的秩序 (Grid System)

為了確保在不同位面（裝置）都能維持美學，我們必須遵循 **柵格律法**：
1.  **手機位面 (Mobile)**：4 欄配置，精簡而有力。
2.  **平板位面 (Tablet)**：8 欄配置，兼顧彈性。
3.  **電腦位面 (Desktop)**：12/24 欄配置，支援複雜的資訊展示。

> [!TIP] 佈局建議
> 善用 **「留白」(Whitespace)**。適度的空白能讓使用者的視覺靈魂得到休息，也能更清晰地劃分資訊邊界。

### 步驟 3：掌握元件間距的運用

*   **學習如何使用間距來組織和引導用戶的視覺：** 內邊距、外邊距。
    *   **內邊距（Padding）：** 指的是控件內容與邊框之間的距離。適當的內邊距可以提高控件的可讀性和美觀性。例如，在一個按鈕中，增加內邊距可以讓文字與邊框之間有更多的空間，看起來更加舒適。
    *   **外邊距（Margin）：** 指的是控件與其他元素之間的距離。適當的外邊距可以避免元素之間過於擁擠，提高界面的整體美觀性。例如，在一個列表中，增加外邊距可以讓列表項之間有更多的空間，看起來更加清晰。
*   **了解不同間距的視覺效果：** 緊湊、寬鬆等。
    *   **緊湊：** 指的是元素之間距離較小，適用於信息密度較高的界面。
    *   **寬鬆：** 指的是元素之間距離較大，適用於需要突出重點或提高可讀性的界面。

### 步驟 4：熟悉主流設計規範

*   **Google Material Design：**
    *   特點：以卡片式設計、動畫效果和生動的色彩著稱，提供一致的視覺和互動體驗。
    *   適用：Android、Web
*   **Human Interface Guidelines：**
    *   特點：專注於 Apple 平台的設計，強調清晰度、易用性和一致性。
    *   適用：iOS、macOS、watchOS、tvOS
*   **Open Design System：**
    *   特點：開放且靈活的設計系統，允許客製化和跨平台應用。
    *   適用：跨平台
*   **Ant Design：**
    *   特點：提供豐富的組件和樣式，適用於企業級產品，注重效率和一致性。
    *   適用：React

### 步驟 5：實作 UI 設計

*   **框架化 UI - 框架圖思考：** 建立 UI 框架，透過框架圖（Wireframe）來規劃介面，專注於內容結構與功能，而非視覺細節。
*   **組件 - 模組化 UI 設計：** 將 UI 拆解為可重複使用的組件，例如按鈕、輸入框等。設計時思考如何組合這些組件，並關注組件的靈活性和可維護性。更改母組件時，其餘組件也會同時修改。
*   **客製化組件庫 - 自定義組件庫：** 建立符合特定專案或組織需求的組件，提供高度靈活性、可重用性和一致的風格。

### 步驟 6：掌握栅格系統 (Grid System)
*   **定義：** 柵格系統是一種在 UI 設計中使用的結構化佈局方法，它將頁面劃分為一系列的欄（columns）和行（rows），幫助設計師對齊和組織內容，確保視覺一致性和平衡。
*   **與網格 (Grid) 的差異：**
    *   **網格 (Grid)：** 是一個更廣泛的概念，可以指任何形式的網狀結構，例如在繪圖軟體中的參考線網格。
    *   **柵格系統 (Grid System)：** 專指用於頁面佈局的、具有特定欄數和間距的網格結構。
*   **手機（Mobile）：** 通常採用 4 欄柵格佈局。欄寬一般在 60-80px 之間，邊距約為 16-20px。適合小螢幕，內容簡潔，易於點擊和瀏覽。
*   **平板（Tablet）：** 常用 8 欄柵格佈局。欄寬與手機類似，但整體寬度更大，邊距可適當增加到 24-32px。適合中等螢幕，內容可以更豐富。
*   **電腦（Desktop/PC）：** 最常見的是 12 欄柵格佈局（有時也用 24 欄，尤其是資訊量大的後台系統）。欄寬通常在 60-80px，邊距可達 32px 或更大。
*   **參考尺寸與斷點：**
    *   手機：320px ~ 480px（4 欄）
    *   平板：768px ~ 1024px（8 欄）
    *   電腦：1200px ~ 1920px（12 欄）
