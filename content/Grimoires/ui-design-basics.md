# 🎨 UI 設計入門：從基礎到實作
#教學 #UI/UX

### 步驟 1：培養 UI 理論基礎

*   **學習 UI 設計的基本原則：** 視覺層次、平衡、對比等。
    *   **視覺層次：** 指的是在 UI 界面中，不同元素的重要性排序。通過調整元素的大小、顏色、位置等，引導用戶的視線，讓他們首先關注最重要的信息。例如，將主要標題設置為較大的字體，並放置在頁面頂部，以吸引用戶的注意力。
    *   **平衡：** 指的是 UI 界面的視覺穩定性。可以通過對稱或非對稱的方式實現。對稱平衡給人一種穩定、正式的感覺，而非對稱平衡則更具活力和現代感。例如，在一個電商網站中，可以將商品圖片和價格信息對稱地排列，以營造一種專業和可信賴的感覺。
    *   **對比：** 指的是 UI 界面中不同元素之間的差異。通過調整顏色、字體、大小等，使某些元素更加突出，從而吸引用戶的注意力。例如，可以使用鮮豔的顏色來標記重要的按鈕或鏈接，使其在頁面中更加醒目。
*   **熟悉設計師常用的詞彙和概念：** 留白、網格系統、色彩搭配。
    *   **留白：** 指的是 UI 界面中元素之間的空白區域。適當的留白可以提高界面的可讀性和美觀性，讓用戶的眼睛得到休息。例如，在一個文章頁面中，增加段落之間的留白，可以讓用戶更容易閱讀和理解文章的內容。
    *   **網格系統：** 是一種將 UI 界面劃分為一系列網格線的佈局方法。使用網格系統可以幫助設計師對齊和組織元素，使界面看起來更加整潔和專業。例如，可以使用 12 列的網格系統來設計一個網站的首頁，確保所有元素都按照網格線對齊。
    *   **色彩搭配：** 指的是在 UI 界面中使用不同的顏色來創造視覺效果。合理的色彩搭配可以提高界面的美觀性和可用性，並傳達特定的情感或信息。例如，可以使用藍色和白色來設計一個企業網站，傳達專業、可靠和信任的感覺。

### 步驟 2：了解控件的特性和使用場景

*   **學習不同控件的特性和使用場景：** 按鈕、文本框、下拉選單等。
    *   **按鈕：** 用於觸發某個操作。常見的按鈕樣式包括：
        *   **主要按鈕：** 用於最重要的操作，通常使用鮮豔的顏色和較大的字體。
        *   **次要按鈕：** 用於不太重要的操作，通常使用較淡的顏色和較小的字體。
        *   **圖標按鈕：** 使用圖標代替文字，更加簡潔和直觀。
    *   **文本框：** 用於接收用戶輸入的文本信息。需要考慮文本框的尺寸、字體、邊框樣式等。
    *   **下拉選單：** 用於從多個選項中選擇一個。需要考慮選項的數量、排列方式、默認選項等。
*   **了解控件的狀態和互動效果：** 懸停、點擊、禁用等。
    *   **懸停：** 當鼠標懸停在控件上時的狀態。通常使用顏色變化、陰影等效果來提示用戶。
    *   **點擊：** 當用戶點擊控件時的狀態。通常使用動畫效果、聲音等來反饋用戶。
    *   **禁用：** 當控件不可用時的狀態。通常使用灰色、透明度降低等效果來表示。

### 步驟 3：掌握元件間距的運用

*   **學習如何使用間距來組織和引導用戶的視覺：** 內邊距、外邊距。
    *   **內邊距（Padding）：** 指的是控件內容與邊框之間的距離。適當的內邊距可以提高控件的可讀性和美觀性。例如，在一個按鈕中，增加內邊距可以讓文字與邊框之間有更多的空間，看起來更加舒適。
    *   **外邊距（Margin）：** 指的是控件與其他元素之間的距離。適當的外邊距可以避免元素之間過於擁擠，提高界面的整體美觀性。例如，在一個列表中，增加外邊距可以讓列表項之間有更多的空間，看起來更加清晰。
*   **了解不同間距的視覺效果：** 緊湊、寬鬆等。
    *   **緊湊：** 指的是元素之間距離較小，適用於信息密度較高的界面。
    *   **寬鬆：** 指的是元素之間距離較大，適用於需要突出重點或提高可讀性的界面。

### 步驟 4：熟悉主流設計規範

*   **Google Material Design：**
    *   特點：以卡片式設計、動畫效果和生動的色彩著稱，提供一致的視覺和互動體驗。
    *   適用：Android、Web
*   **Human Interface Guidelines：**
    *   特點：專注於 Apple 平台的設計，強調清晰度、易用性和一致性。
    *   適用：iOS、macOS、watchOS、tvOS
*   **Open Design System：**
    *   特點：開放且靈活的設計系統，允許客製化和跨平台應用。
    *   適用：跨平台
*   **Ant Design：**
    *   特點：提供豐富的組件和樣式，適用於企業級產品，注重效率和一致性。
    *   適用：React

### 步驟 5：實作 UI 設計

*   **框架化 UI - 框架圖思考：** 建立 UI 框架，透過框架圖（Wireframe）來規劃介面，專注於內容結構與功能，而非視覺細節。
*   **組件 - 模組化 UI 設計：** 將 UI 拆解為可重複使用的組件，例如按鈕、輸入框等。設計時思考如何組合這些組件，並關注組件的靈活性和可維護性。更改母組件時，其餘組件也會同時修改。
*   **客製化組件庫 - 自定義組件庫：** 建立符合特定專案或組織需求的組件，提供高度靈活性、可重用性和一致的風格。

### 步驟 6：掌握栅格系統 (Grid System)
*   **定義：** 柵格系統是一種在 UI 設計中使用的結構化佈局方法，它將頁面劃分為一系列的欄（columns）和行（rows），幫助設計師對齊和組織內容，確保視覺一致性和平衡。
*   **與網格 (Grid) 的差異：**
    *   **網格 (Grid)：** 是一個更廣泛的概念，可以指任何形式的網狀結構，例如在繪圖軟體中的參考線網格。
    *   **柵格系統 (Grid System)：** 專指用於頁面佈局的、具有特定欄數和間距的網格結構。
*   **手機（Mobile）：** 通常採用 4 欄柵格佈局。欄寬一般在 60-80px 之間，邊距約為 16-20px。適合小螢幕，內容簡潔，易於點擊和瀏覽。
*   **平板（Tablet）：** 常用 8 欄柵格佈局。欄寬與手機類似，但整體寬度更大，邊距可適當增加到 24-32px。適合中等螢幕，內容可以更豐富。
*   **電腦（Desktop/PC）：** 最常見的是 12 欄柵格佈局（有時也用 24 欄，尤其是資訊量大的後台系統）。欄寬通常在 60-80px，邊距可達 32px 或更大。
*   **參考尺寸與斷點：**
    *   手機：320px ~ 480px（4 欄）
    *   平板：768px ~ 1024px（8 欄）
    *   電腦：1200px ~ 1920px（12 欄）
