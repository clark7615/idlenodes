# 🏢 公司價值評估：4 維度 1 矩陣，判斷值不值得拼

**一間公司值不值得傾盡全力？用四個核心維度——成長、回報、文化、風險——搭配一張填空矩陣，30 分鐘內得出客觀結論，告別直覺判斷。這種判斷最好每半年到一年問自己一次：是否需要重新評估這段關係了？**


## 第一維度:**值得***該不該繼續拼下去*

判斷標準不在「公司好不好」，而在 **「你與公司的資源交換是否正向累積」**。
### 思維模型：通用資本 vs 專用資本

人分成兩類——**通用資本型** 與 **專用資本型**。

| 類型 | 對誰好 | 怎麼來 | 範例 |
|------|--------|--------|------|
| **通用資本** | 對我好，去哪都能換 | 自己挖掘、自己學習、自己累積 | 產業知識、管理能力、人脈、聲譽 |
| **專用資本** | 對公司好用，綁住你 | 公司培訓，讓公司更高效 | 內部系統操作、封閉技術棧、老闆喜好 |

| 場景 | 通用資本 | 專用資本 |
|------|----------|----------|
| 創業公司 | ✅ 學習通用資本的好地方 | ❌ 沒有能力提供專用資本 |
| 大廠 | ❌ 很難學到通用資本 | ✅ 專用資本很充足 |

> 若你累積的多是專用資本，你會被綁死；若多是通用資本，你隨時有選擇權。

---

#### 📖 經典案例：同一家律所，兩個律師

同樣的努力、相同的資歷，幾年後境遇卻完全相反——差別只在 **資本是哪一種**。

| | 專用資本律師 | 通用資本律師 |
|---|---|---|
| 崗位性質 | 只有這家律所才有的崗位 | 市場通用的律師 |
| 能力對價 | 能力很強卻沒有市場公開對價 | 能力在外部有明顯的報價 |
| 議價權 | 升職加薪公司說了算，被焊死在原地 | 一份競爭者來，公司為了留人不得不破格漲薪 |

> **決定你議價權的，不是你多強，是你的能力有沒有市場報價。**

#### 給公司的啟示

公平對待兩種資本的員工：
- 專用資本員工 → 給予長期承諾、內部升遷路徑
- 通用資本員工 → 給予市場競爭力薪酬、成長空間

#### 🎯 總結：該不該繼續拚？

**如果你是專用資本型：**
- 主動提取工作中的通用知識（原理 > 工具）
- 建立外部人脈與個人品牌
- 定期出去面試，為自己的市場能力定價

**如果你是通用資本型：**
- 持續累積可攜帶的作品與聲譽
- 選擇能放大你通用能力的平台
- 用市場報價作為談判籌碼，不讓公司低估你

容易被光環騙——大廠名稱好、聽起來穩定，但這些是**公司好，未必是你的複利**。

真正該問的是：

> **一年之後我帶得走什麼？**
> **這段經歷讓我下一步更值錢，還是更便宜？**

## 填空矩陣：四類工作判定法

將工作依 **是否會複利**（Y 軸）與 **獲利歸屬**（X 軸）分成四大類：

|          | 獲利歸公司       | 獲利歸我自己    |
| -------- | ----------- | --------- |
| **不會複利** | **① 苦勞型**   | **② 交易型** |
| **會複利**  | **③ 專用資本型** | **④ 槓桿型** |

---

### ① 苦勞型 — 不會複利 × 獲利歸公司

**特徵**：做完就沒了，公司拿走成果，你沒有任何累積。公司用你的唯一理由——**因爲你便宜**。

| 面向 | 描述 |
|------|------|
| 典型場景 | 重複性報表、行政庶務、救火除錯、基層執行 |
| 你的處境 | 工時越長越累，技能沒有增長，走了馬上有人補 |
| 公司角度 | 你是一顆可替換的螺絲釘，留你只因為成本划算 |
| 核心邏輯 | 你的價值 = 你的替代成本，不是你的貢獻 |
| 行動建議 | 快速做完或設法自動化，不要在這區戀戰 |

### 月薪是導致貧窮的原因

苦勞型工作最致命的不是薪水低，而是它的**交換邏輯**：

| 陷阱 | 說明 |
|------|------|
| ⏳ 時間換錢 | 你一小時不工作，就少一小時的錢。收入上限 = 時數 × 時薪，無法突破 |
| 📉 沒有殘值 | 這一個月做的事，下個月歸零。經驗不疊加，履歷不增值 |
| 🔄 通膨吃薪 | 薪水漲幅追不上物價，實際購買力逐年下滑 |
| 🧱 機會成本 | 投入苦勞的時間，無法拿去學技能、做副業、建立被動收入 |

**核心邏輯**：月薪讓你把最稀缺的資源（時間）賣給公司，換來的是用完就沒有的現金。只要你的收入完全依賴「出售時間」，你就永遠在貧窮線附近掙扎——不管月薪數字是多少。

> 🔴 **口訣**：苦勞不留名，便宜是唯一原因，做完快逃命。

---
### ② 交易型 — 不會複利 × 獲利歸我自己

**特徵**：事情歸你，錢進你口袋，但一單一單來，沒有複利。最多能帶走的只有客戶。

| 面向 | 描述 |
|------|------|
| 典型場景 | 業務銷售、仲介、接案 freelancer、計件工作者 |
| 你的處境 | 這單做完找下一單，收入永遠從零開始 |
| 公司角度 | 你自帶生產力，公司提供平台抽成，雙方各取所需 |
| 核心瓶頸 | 最多能帶走的只有客戶關係，無法規模化 |
| 突圍方向 | 建立系統（管理、培訓、品牌），把經驗複製出去 |

> 厲害的銷售不會一直做銷售，而是做**銷售管理與培訓**——把一對一的交易能力，變成一套可複製的系統。

> 🟠 **口訣**：交易型做完歸零，想破局就得建系統。

---

### ③ 專用資本型 — 會複利 × 獲利歸公司

**特徵**：技能持續累積，但全是公司專用的封閉技術棧，離開就報廢。

| 面向 | 描述 |
|------|------|
| 典型場景 | 大廠自研框架、內部工具鏈、專利流程、封閉生態系 |
| 你的處境 | 奉獻青春學了一身功夫，出去卻沒人認可、無處可用 |
| 公司角度 | 用高薪與光環綁住你，你的專用資本就是你的金手銬 |
| 行動建議 | 設法提取通用知識（原理 > 工具），同步經營外部能見度 |

| 陷阱 | 說明 |
|------|------|
| 🌟 光環效應 | 大廠招牌讓你誤以爲自己很值錢，直到面試下一家才醒 |
| 🔗 路徑依賴 | 年資越深越難離開，因為機會成本被墊高了 |
| 🧠 知識偏食 | 只懂內部最佳實踐，不懂業界通用解法 |

> 🟡 **口訣**：專用資本深似海，趁早提取通用才。

---

### ④ 槓桿型 — 會複利 × 獲利歸我自己

**特徵**：努力存在自己身上——用公司的資源，辦客戶的事，長自己的本事。技能、聲譽、作品集全部複利疊加，換公司也帶得走。

| 面向 | 描述 |
|------|------|
| 典型場景 | 有作品的工程師、顧問、架構師、創業前的儲備期 |
| 你的處境 | 每一次交付都在爲自己的履歷和品牌增值 |
| 公司角度 | 你的產出服務客戶，公司賺服務費，你賺能力 |
| 核心原則 | 努力必須存在自己身上，而不只是留在公司的報表裏 |
| 行動建議 | 繼續待，直到這份工作掉到其他象限 |

#### 上班三件事

```
用公司的支援 🛠️ → 辦客戶的事 🎯 → 長自己的本事 🧠
```

1. **用公司的支援** — 平台、資源、品牌光環，都是你的槓桿
2. **辦客戶的事** — 對得起這份薪水，產出真正的價值
3. **長自己的本事** — 提煉成通用能力、作品、案例、人脈

> 🟢 **口訣**：公司是修道場，本事長身上，什麼時候走都不慌。
