# 🏢 公司價值評估：4 維度 1 矩陣，判斷值不值得拼

**一間公司值不值得傾盡全力？用四個核心維度——值得、努力、在此、你——搭配一張填空矩陣，30 分鐘內得出客觀結論，告別直覺判斷。這種判斷最好每半年到一年問自己一次：是否需要重新評估這段關係了？**


# 第一維度：值得 — 該不該繼續拼下去

判斷標準不在「公司好不好」，而在 **「你與公司的資源交換是否正向累積」**。
### 思維模型：通用資本 vs 專用資本

人分成兩類——**通用資本型** 與 **專用資本型**。

| 類型 | 對誰好 | 怎麼來 | 範例 |
|------|--------|--------|------|
| **通用資本** | 對我好，去哪都能換 | 自己挖掘、自己學習、自己累積 | 產業知識、管理能力、人脈、聲譽 |
| **專用資本** | 對公司好用，綁住你 | 公司培訓，讓公司更高效 | 內部系統操作、封閉技術棧、老闆喜好 |

| 場景 | 通用資本 | 專用資本 |
|------|----------|----------|
| 創業公司 | ✅ 學習通用資本的好地方 | ❌ 沒有能力提供專用資本 |
| 大廠 | ❌ 很難學到通用資本 | ✅ 專用資本很充足 |

> 若你累積的多是專用資本，你會被綁死；若多是通用資本，你隨時有選擇權。

---

#### 📖 經典案例：同一家律所，兩個律師

同樣的努力、相同的資歷，幾年後境遇卻完全相反——差別只在 **資本是哪一種**。

| | 專用資本律師 | 通用資本律師 |
|---|---|---|
| 崗位性質 | 只有這家律所才有的崗位 | 市場通用的律師 |
| 能力對價 | 能力很強卻沒有市場公開對價 | 能力在外部有明顯的報價 |
| 議價權 | 升職加薪公司說了算，被焊死在原地 | 一份競爭者來，公司為了留人不得不破格漲薪 |

> **決定你議價權的，不是你有多強，是你的能力有沒有市場報價。**

#### 給公司的啟示

公平對待兩種資本的員工：
- 專用資本員工 → 給予長期承諾、內部升遷路徑
- 通用資本員工 → 給予市場競爭力薪酬、成長空間

#### 🎯 總結：該不該繼續拚？

**如果你是專用資本型：**
- 主動提取工作中的通用知識（原理 > 工具）
- 建立外部人脈與個人品牌
- 定期出去面試，為自己的市場能力定價

**如果你是通用資本型：**
- 持續累積可攜帶的作品與聲譽
- 選擇能放大你通用能力的平台
- 用市場報價作為談判籌碼，不讓公司低估你

容易被光環騙——大廠名稱好、聽起來穩定，但這些是**公司好，未必是你的複利**。

真正該問的是：

> **一年之後我帶得走什麼？**
> **這段經歷讓我下一步更值錢，還是更便宜？**

---
## 填空矩陣：四類工作判定法

將工作依 **是否會複利**（Y 軸）與 **獲利歸屬**（X 軸）分成四大類：

|          | 獲利歸公司       | 獲利歸我自己    |
| -------- | ----------- | --------- |
| **不會複利** | **① 苦勞型**   | **② 交易型** |
| **會複利**  | **③ 專用資本型** | **④ 槓桿型** |

---

### ① 苦勞型 — 不會複利 × 獲利歸公司

**特徵**：做完就沒了，公司拿走成果，你沒有任何累積。公司用你的唯一理由——**因爲你便宜**。

| 面向 | 描述 |
|------|------|
| 典型場景 | 重複性報表、行政庶務、救火除錯、基層執行 |
| 你的處境 | 工時越長越累，技能沒有增長，走了馬上有人補 |
| 公司角度 | 你是一顆可替換的螺絲釘，留你只因為成本划算 |
| 核心邏輯 | 你的價值 = 你的替代成本，不是你的貢獻 |
| 行動建議 | 快速做完或設法自動化，不要在這區戀戰 |

### 月薪是導致貧窮的原因

苦勞型工作最致命的不是薪水低，而是它的**交換邏輯**：

| 陷阱 | 說明 |
|------|------|
| ⏳ 時間換錢 | 你一小時不工作，就少一小時的錢。收入上限 = 時數 × 時薪，無法突破 |
| 📉 沒有殘值 | 這一個月做的事，下個月歸零。經驗不疊加，履歷不增值 |
| 🔄 通膨吃薪 | 薪水漲幅追不上物價，實際購買力逐年下滑 |
| 🧱 機會成本 | 投入苦勞的時間，無法拿去學技能、做副業、建立被動收入 |

**核心邏輯**：月薪讓你把最稀缺的資源（時間）賣給公司，換來的是用完就沒有的現金。只要你的收入完全依賴「出售時間」，你就永遠在貧窮線附近掙扎——不管月薪數字是多少。

> 🔴 **口訣**：苦勞不留名，便宜是唯一原因，做完快逃命。

---
### ② 交易型 — 不會複利 × 獲利歸我自己

**特徵**：事情歸你，錢進你口袋，但一單一單來，沒有複利。最多能帶走的只有客戶。

| 面向 | 描述 |
|------|------|
| 典型場景 | 業務銷售、仲介、接案 freelancer、計件工作者 |
| 你的處境 | 這單做完找下一單，收入永遠從零開始 |
| 公司角度 | 你自帶生產力，公司提供平台抽成，雙方各取所需 |
| 核心瓶頸 | 最多能帶走的只有客戶關係，無法規模化 |
| 突圍方向 | 建立系統（管理、培訓、品牌），把經驗複製出去 |

> 厲害的銷售不會一直做銷售，而是做**銷售管理與培訓**——把一對一的交易能力，變成一套可複製的系統。

> 🟠 **口訣**：交易型做完歸零，想破局就得建系統。

---

### ③ 專用資本型 — 會複利 × 獲利歸公司

**特徵**：技能持續累積，但全是公司專用的封閉技術棧，離開就報廢。

| 面向 | 描述 |
|------|------|
| 典型場景 | 大廠自研框架、內部工具鏈、專利流程、封閉生態系 |
| 你的處境 | 奉獻青春學了一身功夫，出去卻沒人認可、無處可用 |
| 公司角度 | 用高薪與光環綁住你，你的專用資本就是你的金手銬 |
| 行動建議 | 設法提取通用知識（原理 > 工具），同步經營外部能見度 |

| 陷阱 | 說明 |
|------|------|
| 🌟 光環效應 | 大廠招牌讓你誤以爲自己很值錢，直到面試下一家才醒 |
| 🔗 路徑依賴 | 年資越深越難離開，因為機會成本被墊高了 |
| 🧠 知識偏食 | 只懂內部最佳實踐，不懂業界通用解法 |

> 🟡 **口訣**：專用資本深似海，趁早提取通用才。

---

### ④ 槓桿型 — 會複利 × 獲利歸我自己

**特徵**：努力存在自己身上——用公司的資源，辦客戶的事，長自己的本事。技能、聲譽、作品集全部複利疊加，換公司也帶得走。

| 面向 | 描述 |
|------|------|
| 典型場景 | 有作品的工程師、顧問、架構師、創業前的儲備期 |
| 你的處境 | 每一次交付都在爲自己的履歷和品牌增值 |
| 公司角度 | 你的產出服務客戶，公司賺服務費，你賺能力 |
| 核心原則 | 努力必須存在自己身上，而不只是留在公司的報表裏 |
| 行動建議 | 繼續待，直到這份工作掉到其他象限 |

#### 上班三件事

```
用公司的支援 🛠️ → 辦客戶的事 🎯 → 長自己的本事 🧠
```

1. **用公司的支援** — 平台、資源、品牌光環，都是你的槓桿
2. **辦客戶的事** — 對得起這份薪水，產出真正的價值
3. **長自己的本事** — 提煉成通用能力、作品、案例、人脈

> 🟢 **口訣**：公司是修道場，本事長身上，什麼時候走都不慌。

#### ✅ 今天就能做的事

1. **把自己的工作放進矩陣** — 你現在最多的時間落在哪個象限？
2. **如果你明天離職，你能帶走的三樣東西是什麼？** — 寫下來，看看是通用資本還是專用資本

---

# 第二維度：努力 — 需要被定價

你做了 80% 的活，匯報時功勞寫著別人的名字。苦勞沒人看得見，只有能歸因到你的結果，才會被定價。

> 這與 **形象管理** 息息相關——你的產出必須能被「正確歸因」，否則努力只是自我感動。

### 信號倫理與結果歸因

公司看不見你的投入，只能看見**可被歸因到你名下的結果**——能被觀測的，才能被定價。

**你以爲你在攢的**：時長、苦勞、隨叫隨到——記住，只有你知道，離職即清零。

**公司定價的是**：別人複述得出、能寫進晉升材料、能歸因到你名字的那一件結果。

| 陷阱 | 說明 |
|------|------|
| 👻 隱形貢獻 | 活你幹的，功勞是別人的，主管看不見你 |
| 📉 無差別努力 | 埋頭苦幹卻不懂包裝，產出被稀釋在團隊裏 |
| 🏷️ 歸因失敗 | 沒有標籤化的成果，就無法轉化為你的議價權 |

> 💡 **關鍵心態**：可以保有踏實與低調的品格，但該你上場彙報時，你也要有彙報的能力。**不搶功，但不讓功被搶。**

#### ⚠️ 背鍋俠的成因

做好的結果從來沒歸因到你身上，那做不好的結果肯定在你身上。**功勞沒有歸因權，過錯就會有歸屬權。**

> 不是你不夠好，是你的努力沒有被正確貼標籤。

**行動方向**：讓每一份努力都有「署名權」——不是邀功，而是確保功勞回到該回的人身上。

#### 好信號的標準

信號的標準是什麼？**越難取得、越難造假的信號，就是好信號。**

| 弱信號 | 強信號 |
|--------|--------|
| 說自己很努力 | 有具體數據的業績紀錄 |
| 主管口頭誇獎 | 晉升材料裏白紙黑字的歸因 |
| 工時長、隨叫隨到 | 業界知名度、客戶指名 |
| 內部好評 | 外部 offer、市場報價 |

> 真正的信號，是那些你無法假裝、對手無法複製的成果。

#### ✅ 今天就能開始做的事

1. **把本週工作翻譯成 3 句結果句**：動詞 + 可量化結果 + 歸因到我
2. **挑一個成果，讓至少一個決策者親眼看見，並且記住是你做的**

> 📡 **信號倫理總結**：發信號，別人才會注意到。會叫的輪子有更多的油滋潤——但不要過猶不及。

# 第三維度：在此 — 組織裡有你的一席之地嗎？

你在小組裡最強悍，但三年了主管位置一直沒換到你頭上。

> **決定你能不能升的，常常不是你多強，而是這組織裡還有沒有空位。**

想要升職，只有三條路：

| 路徑 | 做法 | 難度 |
|------|------|------|
| 🚀 **把領導弄上去** | 幫主管升遷，他的位置就是你的 | 需要你夠可靠，主管願意拉你一把 |
| ⚔️ **把他拉下來** | 績效超越他，或讓他犯錯被換掉 | 政治風險高，傷敵一千自損八百 |
| 🏃 **把自己賣出去** | 跳槽到有位置的地方 | 最乾脆，但前提是你在市場上有報價 |

### 錦標賽理論

晉升獎勵的是 **相對排名**，不是絕對努力——空位有限，比的是位次。相同的努力，平台不同，係數不同。

| 你以爲的算法 | 真正算的 |
|-------------|---------|
| 我今年比去年更拼了，做了更多 → 絕對努力在上漲 | 在這群人、這個組織內我排第幾？ |
| 努力 = 回報 | 未來有沒有新的位置？我的排名是否能上去？ |

> **相對第一才會有獎勵。**

---

#### ✅ 今天就能做的事

1. **公司未來兩年會不會有新的崗位？** — 沒有空位，再強也沒用
2. **你在公司這群人的相對位置，在變好還是變差？** — 跟同儕比，不是跟自己比

> 💡 **關鍵前提**：升你，然後呢？你的坑誰填？
> 
> 所以一定要帶徒弟。**讓自己可以被取代，才有資格被升遷。** 如果你走了團隊就垮，公司反而會把你焊死在原位。

---

# 第四維度：你 — 別忘記止損

**「再等等看吧」——這句話你對自己說了第幾年？**

不動，感覺最安全，可它正在用複利，悄悄收你的費。

### 零和思維

當這件事對你沒有複利，那肯定是別人的複利。**你的停滯，就是別人的槓桿。**

| 你以爲的 | 實際發生的 |
|----------|-----------|
| 我再等等，時機成熟再說 | 你的青春、精力、機會成本，全變成主管的業績、公司的利潤 |
| 穩定就好，不想折騰 | 你的可替代性正在累積複利——對公司來說 |
| 不做選擇 | 不做選擇本身就是一種選擇——而且通常是最差的 |

### 不作為偏誤 vs 公正世界信念

**不作為偏誤**：人們傾向認為「不做行動」比「做了錯誤行動」更安全——因為不行動的壞結果看起來不像自己的責任。但這只是心理上的舒適，不是真實的零成本。

**公正世界信念**：一種認知偏誤，認為世界是公平的——努力就會有回報、等待就會被看見。但組織的晉升邏輯不遵循道德正義，它遵循的是空位與賽局規則。

不值得還硬留，感覺零風險，其實在虧複利——**機會成本，是最貴的隱性帳單。**

| 你以爲的 | 真相 |
|----------|------|
| 待著 = 安全 | 待著 = 虧複利 |
| 不換，就沒有「做錯誤決定」的風險，心理上是零成本 | 每多待一年在不複利的地方，你同齡人的差距，在以複利擴大 |

> **你以爲的不動是在省錢，其實是在欠債——欠自己一個未來。**

### 那要怎麼動？

**謀定而後動**——但謀的時候，本身就是動了。

你在思考、你在規劃，這就是動。接下來就是執行。

#### ✅ 今天就能做的事

1. **設定一條止損線**：什麼條件還沒出現，你就啟動找下家？
2. **用第三人稱問自己**：如果最好的朋友在這裡，我會勸他留下，還是走？

---

# 結論

不要「再等等看」，它是在用複利，偷走你的機會成本，換一份虛假的安心。

> **每一段不確定的等待，都在用你的人生支付利息。**

現在就拿出矩陣，把你的工作放進去——四個維度打完分，你心裡就有答案了。
