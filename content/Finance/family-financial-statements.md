# 📊 魔法家計簿：家庭財務偵查術

> [!BOOK] 法典引言
> 在冒險者的堡壘中，了解自己的實力與資源是生存的關鍵。**魔法家計簿** 是用來編制與分析家庭財務報表的神秘卷軸，讓你清楚知道自己擁有什麼、欠了什麼、以及金幣流向何處。

---

## 核心概念：兩張關鍵卷軸

你可能會問：「我只需要知道我賺多少、花多少就好了，為什麼要做卷軸？」答案是：**卷軸能幫你看見「隱藏的問題」**。

### 兩張核心卷軸

| 卷軸 | 時間維度 | 用途 |
|:---|:---|:---|
| 📋 資產負債卷 | 某一時間點（如 12/31） | 了解「你擁有什麼」 |
| 📈 收支儲蓄卷 | 某一期間（如 11/1-11/30） | 了解「金幣流向」 |

---

## 📜 卷軸一：資產負債卷

### 基本公式

$$資產 - 負債 = 淨值（所有者權益）$$

這張卷軸告訴你在某個時間點的財務全貌。

### 資產分類

| 類別 | 說明 | 範例 |
|:---|:---|:---|
| 🏭 生產性資產 | 會自行孳生收益的資產 | 現金、存款、股票、基金、不動產投資 |
| 🏠 自用資產 | 不會孳生收益的資產 | 自用住宅、汽車、機車 |

### 負債分類

| 類別 | 說明 | 範例 |
|:---|:---|:---|
| 🏠 自用資產負債 | 購買自用資產產生的貸款 | 房貸、車貸 |
| 📈 投資負債 | 借錢來投資產生的貸款 | 股票融資、理財型房貸 |
| 🛒 消費負債 | 消費行為產生的負債 | 信用卡帳款、分期付款 |

### 範例：家庭資產負債卷

| 資產 | 金額 | 負債 | 金額 |
|:---|:---|:---|:---|
| **生產性資產** | | **投資負債** | |
| 現金 | $10,000 | 證券融資餘額 | $50,000 |
| 活儲 | $50,000 | **投資負債小計** | **$50,000** |
| 定存 | $200,000 | **自用負債** | |
| 股票 | $300,000 | 房貸餘額 | $3,000,000 |
| **生產性資產小計** | **$560,000** | **自用負債小計** | **$3,000,000** |
| **自用資產** | | **消費負債** | |
| 自用住宅 | $5,000,000 | 信用卡帳款 | $30,000 |
| 汽車 | $600,000 | **消費負債小計** | **$30,000** |
| **自用資產小計** | **$5,600,000** | | |
| **總資產合計** | **$6,160,000** | **總負債合計** | **$3,080,000** |
| **淨值** | **$3,080,000** | | |

## 📜 卷軸二：收支儲蓄卷

### 三大組成部分

$$收入 - 支出 = 儲蓄$$

| 部分 | 內容 |
|:---|:---|
| 💰 收入 | 工作收入、理財收入、移轉性收入、其他收入 |
| 💸 支出 | 生活必需、教育、醫療、保險、理財、休閒娛樂 |
| 💎 儲蓄 | 收入減去支出 |

### 範例：家庭收支儲蓄卷

| 項目 | 細項 | 金額 |
|:---|:---|:---|
| **收入** | | |
| 工作收入 | 薪資、獎金 | $60,000 |
| 理財收入 | 利息、股利 | $5,000 |
| **稅前收入合計** | | **$65,000** |
| 所得稅扣繳額 | | $5,000 |
| **稅後收入合計** | | **$60,000** |
| **支出** | | |
| 生活必需 | 食、衣、住、行 | $25,000 |
| 教育 | 子女學費 | $5,000 |
| 保險 | 人壽、醫療險 | $3,000 |
| 理財支出 | 房貸利息 | $10,000 |

## 📊 六大偵查比率

### 1. 負債比率

$$負債比率 = \frac{總負債}{總資產}$$

- **健康標準**：< 0.5
- **意義**：每一元資產中，有多少是借來的
- **警示**：比率越高，財務壓力越大

### 2. 淨值投資比率

$$淨值投資比率 = \frac{生產性資產}{總淨值}$$

- **意義**：衡量資金投資在生產性資產的比率
- **> 100%**：代表借錢投資
- **< 100%**：不代表完全沒借錢投資

### 3. 自由儲蓄率

$$自由儲蓄率 = \frac{自由儲蓄額}{總收入}$$

- **健康標準**：> 10%
- **自由儲蓄額**：總儲蓄額扣除固定儲蓄後的餘額

### 4. 支出比率

$$支出比率 = \frac{總支出}{總收入}$$

- **意義**：衡量支出占收入的比率
- **越低越好**：代表資產累積速度越快

### 5. 財務負擔率

$$財務負擔率 = \frac{理財支出}{總收入}$$

- **健康標準**：< 30%
- **意義**：評估理財支出是否合理

### 6. 相對收支率

$$相對收支率 = \frac{目前收入 / 區域平均收入}{目前支出 / 區域平均支出}$$

- **健康標準**：≥ 1
- **< 1**：代表儲蓄率低於區域平均，應加強儲蓄

## 🔑 核心觀念總結

- **卷軸是診斷工具**：幫你發現隱藏的財務問題
- **定期編制**：建議每月或每季一次
- **比率是關鍵**：單一數字沒有意義，比率才有意義
- **與目標對比**：將比率與你的理財目標比較
