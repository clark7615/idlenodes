# 114學年度下學期「內部稽核概論」第二次平時作業

### 學號：114121000                 姓名：柯升平
## 1. 請說明外部評核效益的項目(共8項)(25分)

1. **與策略目標的一致性**:確保與公司策略計劃及目標一致，因此需持續性關注相關的對話溝通，對部門使命及願景完成情況予以評估。
2. **服務文化**:建立企業內部專業服務諮詢的文化，提升組織的營運效率及風險管理
3. **創新的技術**:通過內部稽核技術，幫忙稽核人員識別風險，提升稽核人員的工作效率，持續關注新的內部稽核技術。
4. **成本效益分析**:注重成本效益分析、優化稽核流程，稽核工作的完成、應合乎成本效益。
5. **持續提升品質**:持續關注品質及標準的設計，鼓勵品質的創新與提升、使之成為企業文化。
6. **以風險為核心的稽核計劃**:關注各項風險動態的變化，以風險管理為導向，展開年步稽核計劃。
7. **人才模式**:合理的訂定人才合作計劃、與內外部專家協作，滿足組織特定的期望建立績效回饋機制等，促進內部稽核長遠發展計劃。
8. **與利益相關者溝通**:持續關注內、外部利害關係人的關聯關係，對於利害關係人的期望、溝通策略等引入適當的回饋機制。

## 2. 請說明重大稽核失敗的常見原因(25分)

1. **受查組織內部控制失效**
2. **高階主管逾越內部控制**
3. **簽證會計師與被受查組織共同舞弊**
4. **稽核部門缺乏獨立性**
5. **內部稽核人員沒有保持應有的職業審查和職業懷疑**

## 3. 請說明稽核的準備工作為何(共三項)(25分)
1. **溝通會議**:
	1. 參與人:主管與功能性人員
	2. 稽核專案溝通:目標、內容、範圍等
	3. 聽取營業組織自我介紹
2. **收集資料**:
	1. 電子檔資料
	2. 紙本檔資料
	3. 其他:如許可權等
3. **現場觀察**:
	1. 營業組織主管及員工狀況
	2. 營業組織工作環境的狀態
## 4. 內部稽核主管稽核發現問題，採取追蹤機制，追蹤機制包括甚麼?(共四項)(25分)
1. 對問題改善措施和行動計劃進行判斷，並給予專業意見。
2. 定期和受查部門溝通改善情況，並對其遇到的障礙給予指導。
3. 進行現場測試，對改進落實的情況進行取證，評估問題改進的效果，並高階主管和治理層級報告改進情況。
4. 對拒絕改進(及主動接受風險)或改進失敗(及被動接受風險)的事項應即時向高階主管和治理層級通報，並促使其了解這一情況。
